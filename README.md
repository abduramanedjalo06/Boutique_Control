# 🏪 Boutique_Control 
A small Python program I created to help me manage sales and finances at my uncle's boutique.

Why I Created It

When my uncle leaves me in charge of the boutique on Saturdays and Sundays or during vacations, he asks me to record everything I sold in a notebook.

It works, but it's very laborious and takes me a long time to write down sales and loans (expenses). Sometimes, customers end up waiting for me. I also made mistakes without realizing it when adding everything up at the end of the day.

So, I decided to use the little programming I've learned to create a simple program to help me do the calculations.
