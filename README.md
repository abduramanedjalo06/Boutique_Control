# 🏪 Boutique_Control

A smart financial management system built to automate daily sales control and cash flow tracking for a local boutique in Guinea-Bissau.

## 📝 The Story Behind the Project
When my uncle leaves me in charge of the boutique, I usually record every single daily sale in a paper notebook. To minimize human error and automate the end-of-day financial balance, I created this software.

## 📊 The Core Formula
The system uses the standard accounting financial equation:
**FB = SB + REV - EXP**

* **SB (Starting Balance):** Cash available when opening the store.
* **REV (Revenue):** Total sales tracked throughout the day.
* **EXP (Expenses):** Any cash taken out for shop expenses or supplier payments.
* **FB (Final Balance):** The exact amount of money that should be in the register at closing time.
